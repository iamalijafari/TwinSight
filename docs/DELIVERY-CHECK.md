# وضعیت بررسی نسخهٔ ۳

## بررسی‌های موفق در این تحویل

- آزمون‌های Node: محاسبات هزینه و منفعت، Trade-off پایلوت، منفعت صفر، تعویق، ورودی نامعتبر، حدود نتیجه‌ها، استقلال snapshot و به‌روزرسانی مرتبط/نامرتبط.
- build: بررسی نحوی JavaScript، خواندن JSON و ساخت سایت استاتیک.
- بسته‌بندی: ساخت ZIP استاتیک و Docker؛ بررسی سلامت CRC و قرارگیری index.html / Dockerfile در ریشهٔ بستهٔ مربوطه.
- بررسی رفتار با DOM شبیه‌سازی‌شده: شروع برنامه، هر سه سناریو، مقایسه، پیش‌نویس و جلوگیری از ثبت تصمیم بر نتیجهٔ قدیمی، حفظ پیش‌نویس هنگام ورود تیکت، ثبت و پاک‌شدن تصمیم، جست‌وجو و فیلتر، dialog شاهد، انتخاب گره با صفحه‌کلید، خروجی JSON، راهنمای پنج‌مرحله‌ای، بازنشانی و فراخوانی چاپ.
- یادداشت دارای HTML به‌صورت متن نمایش داده می‌شود و عنصر اجرایی نمی‌سازد.
- اجرای سرور با HOST=0.0.0.0 و پورت تعیین‌شده: HTML، CSS، ماژول‌ها، JSON و فونت پاسخ ۲۰۰ و MIME مناسب دارند؛ HEAD بدون بدنه، روش نامعتبر ۴۰۵ و مسیر ناموجود ۴۰۴.

ابزار DOM فقط در فضای بررسی استفاده شده و وابستگی جدیدی به پروژه اضافه نکرده است.

## محدودیت‌های تأییدنشده

مرورگر واقعی این محیط هنگام آغاز اجرا متوقف شد. بنابراین screenshot، بررسی بصری موبایل/دسکتاپ و رندر نهایی PDF چاپی تأیید نشده‌اند؛ بررسی DOM جایگزین بررسی بصری نیست. قواعد واکنش‌گرا و چاپ در CSS وجود دارند، اما باید در مرورگر مک یا موبایل مرور شوند.

Docker در محیط حاضر نصب نیست؛ خود تصویر Docker build نشده است. فرمان سرور و binding معادل آن آزمایش شدند. اجرای build واقعی میزبان نیازمند حساب آن است.

استقرار عمومی رانفلر، دسترسی از اینترنت ایران، ظرفیت پلن رایگان حساب و دامنهٔ پایدار هنوز تأیید نشده‌اند. انتشار عمومی یا پرداختی انجام نشده است. فایل workflow، بررسی و تولید بسته را تعریف می‌کند؛ نتیجهٔ اجرای GitHub باید در Actions بررسی شود.

## مرور کوتاه روی دستگاه ارائه

با npm run dev نمونه را باز کنید؛ در عرض‌های ۱۴۴۰، ۷۶۸ و ۳۹۰ پیکسل نوشته‌ها و کنترل‌ها را مرور کنید. سه سناریو را انتخاب کنید، روش اجرا را عوض کنید، تیکت را وارد کنید و تصمیم ثبت کنید. گزارش را با مرورگر PDF کنید؛ فونت و شکست صفحه را ببینید. برای تحویل، لینک پایدار را در حالت ناشناس آزمایش کنید و نسخهٔ محلی را نگه دارید.
