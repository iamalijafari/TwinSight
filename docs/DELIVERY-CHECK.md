# وضعیت بررسی تحویل

## بررسی‌های انجام‌شده

- `npm run build`: بررسی نحوی JavaScript، خواندن JSON و ساخت خروجی استاتیک موفق بود.
- سرویس محلی: HTML، CSS، ماژول‌ها، JSON و فونت با پاسخ HTTP 200 و MIME مناسب دریافت شدند.
- منطق نمونه: پرداخت ۵۹٫۹، انتشار تدریجی ۳۷٫۱، مسیر پرداخت → سفارش‌ها → گزارش فروش، اثر محدود سناریوی گزارش فروش و ثابت‌ماندن دادهٔ سازمان بررسی شدند. در ۵۷۶ ترکیب تنظیمات، شاخص‌ها و تعداد کاربران در حدود تعریف‌شده ماندند.
- بررسی رفتار با DOM شبیه‌سازی‌شده: راه‌اندازی رابط، هر سه preset، انتخاب سرویس با صفحه‌کلید، انتخاب روز، نقشهٔ فعلی/آینده، مقایسه، برچسب نتیجهٔ قبلی، جست‌وجو/فیلتر شاهد، dialog جزئیات، راهنمای پنج‌مرحله‌ای، بازنشانی و محتوای JSON خروجی موفق بودند.
- ساختار YAML workflow و محدودبودن استقرار به main و رویداد غیر Pull Request بررسی شد.

این بررسی‌ها در فضای جدا از پروژه انجام شده‌اند؛ پروژهٔ تست یا وابستگی تست به بسته اضافه نشده است.

## محدودیت مشخص

**بررسی بصری در مرورگر واقعی انجام نشد.** محیط اجرای محلی، امکانات سیستمی لازم برای Chromium را در اختیار ندارد. مرورگر ابری نیز localhost و پروتکل فایل محلی را به دلیل سیاست امنیتی نمی‌پذیرد. بنابراین صحت نمایش نهایی، عدم هم‌پوشانی در اندازه‌های موبایل و کیفیت PDF چاپ‌شده هنوز در مرورگر واقعی تأیید نشده‌اند. بررسی DOM جایگزین بررسی بصری نیست.

workflow در حساب GitHub اجرا نشده و هیچ پوش یا استقرار عمومی انجام نشده است. رفتار واقعی deploy فقط پس از تنظیم Pages و پوش توسط مالک قابل تأیید است.

## بررسی کوتاه پیش از ارائه

با `npm run dev` صفحه را در مرورگر مک باز کنید. پرداخت را اجرا و با انتشار تدریجی مقایسه کنید؛ روی گزارش فروش بزنید؛ گزارش را دریافت کنید. عرض پنجره را کوچک کنید و نقشه را افقی پیمایش کنید. فونت باید Vazirmatn باشد. برای ضبط ارائه، «راهنمای دمو» یا مسیر دو دقیقه‌ای README آماده است.
