# تغییرهای نسخهٔ ۳

مسیر نسخهٔ استاتیک حفظ شده است؛ نیازی به .NET، دیتابیس یا نصب وابستگی نیست. این نسخه ابزار مقایسهٔ دو دیدگاه انسانی نیست؛ نمونهٔ دوقلوی نرم‌افزاری سازمان برای تحلیل پیامد تغییر است.

- رابط، داده و موتور با مسیر تصمیم دربارهٔ فرصت و ریسک بازطراحی شده‌اند.
- نسخهٔ دانش سازمان و ورود یک تیکت ساختگی اضافه شده است.
- محاسبهٔ منفعت، هزینه و روش اجرا قابل بررسی است.
- باقی‌مانده‌های bin/obj مربوط به .NET قدیمی حذف شده‌اند؛ سورس اجرایی .NET در شاخهٔ قبلی وجود نداشت.
- تست‌های Node استاندارد و بسته‌بندی استاتیک/Docker اضافه شده‌اند.
- مستندات قدیمی GitHub Pages با مسیر استقرار مستقل از میزبان جایگزین شده‌اند؛ Pages فعال نمی‌شود.

پس از دریافت تغییرها:

```bash
npm test
npm run dev
npm run package
```

بستهٔ آمادهٔ Docker روی پورت ۸۰۸۰ گوش می‌دهد و فقط فایل‌های همین MVP را نمایش می‌دهد. اطلاعات ارائه‌شده در صفحهٔ دانش همچنان ساختگی‌اند.
