# معماری نسخهٔ نمایشی

یک سایت استاتیک با یک موتور و یک مجموعه داده. مرورگر `public/data/demo.json` را می‌خواند؛ `app.js` وضعیت رابط و رویدادها را کنترل می‌کند؛ `engine.js` یک نتیجهٔ جدید بدون تغییر JSON یا نتیجهٔ قبلی می‌سازد. Node فقط برای اجرا و بسته‌بندی محلی است، نه در زمان استقرار.

## سه مفهوم جدا

1. **نمای سازمان**: سرویس‌ها، روابط، گروه‌های مشتری و شواهد ثابت؛ آماده و فقط خواندنی.
2. **سناریوی تغییر**: شرح، سرویس درگیر، نوع تغییر، درصد کاربران، پوشش آزمون فرضی و انتشار تدریجی.
3. **نتیجه**: مسیر اثر، شاخص‌ها و روزها؛ جدا از نمای سازمان. مقایسه فقط پرچم انتشار تدریجی را عوض می‌کند.

دانش سازمان با وزن‌های یک مدل زبانی یکی نیست. در محصول آینده، connectorها دادهٔ تازه دریافت می‌کنند و ساختار نسخه‌بندی می‌شود؛ تحلیل سناریو نمای سازمان را تغییر نمی‌دهد. این MVP اتصال زنده ندارد و عبارت «زنده» برای وضعیت فعلی دمو استفاده نشده است.

## قواعد روشن محاسبه

اثر پایه = `82 × ضریب نوع × (0.25 + 0.75 × درصد انتشار / 100) × (1 - 0.006 × پوشش آزمون) × ضریب انتشار تدریجی`.

ضریب نوع: تعویض اتصال ۱، قابلیت جدید ۰٫۷۸، بهبود عملکرد ۰٫۵۵ و امنیتی ۰٫۸۸. ضریب انتشار تدریجی ۰٫۶۲ و عادی ۱ است. اثر سرویس هدف در اهمیت آن ضرب می‌شود. هر سرویس دیگر بیشترین اثر دریافتی از مسیرهای جهت‌دار را می‌گیرد، نه مجموع مسیرها. پیکان‌ها جهت انتقال اثرند و الزاماً جهت فراخوانی API نیستند.

شاخص گروه مشتری = بیشترین اثر سرویس مرتبط × حساسیت گروه، با سقف ۹۵. تعداد در معرض اثر = جمعیت نمونه × درصد انتشار × شاخص گروه / ۱۰۰. افزایش تأخیر = اثر × ۲٫۴ میلی‌ثانیه. روزهای ۰، ۱، ۳، ۷، ۱۴ و ۳۰ ضرایب ۰، ۰٫۴۵، ۰٫۸۵، ۱، ۰٫۷۲ و ۰٫۳۸ دارند. رابط چهار روز قابل انتخاب نشان می‌دهد.

همهٔ این ضرایب برای انتقال مفهوم ساخته شده‌اند؛ هیچ کدام ادعای دقت، احتمال خرابی یا تضمین کسب‌وکار نیستند. شاهدها برای توضیح زمینه‌اند؛ متن شاهد یا شرح سناریو توسط AI تحلیل نمی‌شود و مستقیماً اعداد را تغییر نمی‌دهد.

## وضعیت رابط

انتخاب preset نتایج قبلی را پاک می‌کند. ویرایش تنظیمات، نتیجهٔ قبلی را با برچسب نگه می‌دارد و مقایسهٔ جدید را تا اجرای مجدد غیرفعال می‌کند. نقشهٔ فعلی فقط ساختار پایه است؛ کارت‌های پیامد، خروجی آینده در روز انتخابی‌اند. مقایسه همیشه اوج روز هفتم را می‌سنجد و این موضوع کنار اعداد نوشته شده است. گزارش و خروجی JSON مربوط به آخرین اجرای ثبت‌شده‌اند.

نتایج در حافظهٔ صفحه‌اند و با reload پاک می‌شوند. خطا در بارگیری داده پیام قابل مشاهده دارد. عناصر نقشه با Enter و Space قابل انتخاب‌اند؛ dialogهای بومی Escape و مدیریت focus دارند. فونت محلی است و هیچ درخواست خارجی در اجرای رابط وجود ندارد.

## انتخاب فنی

حذف سرور C#، API، مسیر LLM، موتور موازی و پروژه‌های تست، وابستگی استقرار را حذف می‌کند. برای MVP نیازی به React، Vite یا دیتابیس نیست. build در Node استاندارد فقط فایل‌ها را بررسی و کپی می‌کند. همین خروجی روی میزبان استاتیک و GitHub Pages کار می‌کند.
