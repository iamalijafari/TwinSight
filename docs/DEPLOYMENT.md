# استقرار TwinSight

این سایت استاتیک است و در مرورگر اجرا می‌شود. بک‌اند AI، دیتابیس و کلید API لازم ندارد. فونت و دارایی‌ها محلی‌اند. پوشهٔ `dist/` را روی هر هاست استاتیک سازگار می‌توان گذاشت؛ صفحه‌ها با hash جابه‌جا می‌شوند و rewrite لازم ندارند.

## آماده‌سازی

```bash
npm test
npm run package
```

دو بسته ساخته می‌شود:

- `release/TwinSight-static.zip`: برای هاست استاتیک؛ index.html در ریشه است.
- `release/TwinSight-runflare.zip`: برای سرویس Docker؛ Dockerfile در ریشه است و فقط فایل‌های لازم دارد.

## گزینهٔ ایرانی برای دموی رایگان: رانفلر

در بررسی ۲ اکتبر ۲۰۲۶، [صفحهٔ رسمی هاست رایگان رانفلر](https://runflare.com/free-cloud-hosting/) یک پلن آزمایشی سه‌ماهه در کلاستر ایران اعلام می‌کند. این سرویس برای تست و توسعه است؛ پس از سه ماه حذف می‌شود و برای نگهداری دائمی یا دادهٔ حیاتی مناسب نیست. ظرفیت ثبت‌نام و انتخاب پلن باید در حساب خودتان بررسی شود.

### روش فایل ZIP

۱. در [پنل رانفلر](https://portal.runflare.com/) وارد حساب شوید و یک پروژه با پلن رایگان ایجاد کنید. اگر پلن رایگان در حساب موجود نبود، ادامهٔ پولی را بدون تصمیم خودتان انتخاب نکنید.
۲. داخل پروژه یک برنامهٔ Docker ایجاد کنید.
۳. بستهٔ `TwinSight-runflare.zip` را در بخش Drag & Drop بارگذاری کنید. Dockerfile باید در ریشهٔ بسته باشد.
۴. پورت برنامه را ۸۰۸۰ قرار دهید. برنامه با HOST=0.0.0.0 روی این پورت اجرا می‌شود؛ نصب npm یا فرمان build اضافی لازم ندارد.
۵. لاگ ساخت و اجرا را بررسی کنید؛ آدرس اصلی برنامه باید HTML و data/demo.json را باز کند.
۶. دامنه یا زیردامنهٔ حساب را به برنامه متصل و HTTPS را فعال کنید.

منابع: [ساخت برنامهٔ Docker](https://docs.runflare.com/docker/docker-create-app/) و [بارگذاری ZIP](https://docs.runflare.com/docker/deploy-drag-and-drop/).

**محدودیت مهم لینک:** مطابق [راهنمای دامنهٔ موقت](https://docs.runflare.com/general/temporary-domain/)، دامنهٔ موقت رانفلر یک ساعت اعتبار دارد. این آدرس برای تست است، نه لینک دائمی تحویل داوری. لینک پایدار به دامنه/زیردامنهٔ موجود در حساب یا گزینهٔ میزبان دیگری نیاز دارد. رایگان‌بودن دامنهٔ پایدار برای این حساب تأیید نشده است؛ وعدهٔ لینک دائمی رایگان نمی‌دهیم.

### روش اتصال GitHub

بعد از ورود، مطابق [راهنمای اتصال GitHub](https://docs.runflare.com/docker/deploy-github/) برنامه را به `iamalijafari/TwinSight` وصل کنید. فقط همین ریپازیتوری را انتخاب کنید. شاخهٔ دارای تغییرهای جدید را انتخاب و استقرار را آغاز کنید؛ پس از ادغام PR می‌توان main را انتخاب کرد. Dockerfile در ریشه است و سرویس روی پورت ۸۰۸۰ اجرا می‌شود. فعال‌کردن دریافت خودکار اختیاری است.

## گزینهٔ جایگزین: هاست استاتیک ایرانی موجود

اگر هاست رایگان یا فضای استاتیک از قبل دارید، محتویات `TwinSight-static.zip` را در ریشهٔ پوشهٔ عمومی آپلود کنید؛ index.html نباید داخل یک پوشهٔ اضافه باشد. سایت به سرویس پولی دیگری وابسته نیست. SSL و دسترسی ناشناس را بررسی کنید.

در زمان بررسی، [صفحهٔ رسمی لیارا](https://liara.ir/products/free-cloud-host/) اعلام می‌کند ارائهٔ هاست و دیتابیس رایگان تا رفع محدودیت زیرساخت متوقف است؛ بنابراین برای این تحویل روی پلن رایگان لیارا حساب نکرده‌ایم. Netlify و Vercel به‌عنوان سرویس تضمین‌شده برای کاربران ایران پیشنهاد نشده‌اند. GitHub Pages نیز مطابق انتخاب پروژه فعال نشده است.

## اجرای Docker محلی، در صورت نصب Docker

```bash
docker build -t twinsight .
docker run --rm -p 8080:8080 twinsight
```

سپس http://localhost:8080 را باز کنید. Docker فقط فایل‌ها را با Node استاندارد نمایش می‌دهد؛ کوئیری یا دادهٔ کاربر به سرور ارسال نمی‌شود. برای هاست استاتیک، Docker لازم نیست.

## چک پیش از تحویل

- URL را بدون ورود به حساب باز کنید.
- فونت، سه سناریو و نقشه را بررسی کنید.
- ورود تیکت، ثبت تصمیم و گزارش JSON را آزمایش کنید.
- لینک پایدار را در PDF بگذارید؛ تصاویر نمونه را هم داخل PDF قرار دهید.
- نسخهٔ محلی را برای ارائه بدون اینترنت نگه دارید.

این تغییرها سرویس میزبانی جدیدی نساخته‌اند. انتشار عمومی فقط پس از دسترسی به حساب میزبان و دریافت URL موفق قابل تأیید است.
